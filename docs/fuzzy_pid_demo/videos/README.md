# Fuzzy PID Controller Demo on PX4

This folder contains demonstration materials for the Fuzzy PID
attitude controller implemented in PX4 `mc_att_control`.

## Platform

- PX4 Autopilot
- Gazebo Simulation
- MicoAir H743 V2
- STM32H743
- QGroundControl

## Implementation

The Fuzzy PID controller is integrated into the PX4 multicopter
attitude-control module.

## Demo Video

[Watch the Fuzzy PID demonstration](videos/fuzzy_pid_demo.mp4)

## Main Features

- Online adjustment of PID parameters
- Integration with PX4 attitude control
- Simulation using PX4 SITL and Gazebo
- Comparison with the conventional controller
